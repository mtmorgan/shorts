# Project: TypeScript Coding Standards

## Coding Style Rules
- Always use TypeScript for all newly generated or modified files.
- Strictly prefer functional component and functional programming paradigms.
- **Mandatory**: Use **arrow function syntax** (`const myFunction = () => {}`) for all function definitions, react components, hooks, and utility methods.
- Avoid using the traditional `function` keyword unless absolutely required for constructor/prototype contexts.
- Explicitly type function parameters and return types. Avoid using `any`.
